Чотири незалежні задачі на перебираючі методи масивів:

1. `js/task-1.js` — `getUserNames(users)`: імена користувачів через `map()`.
2. `js/task-2.js` — `getUsersWithFriend(users, friendName)`: пошук через `filter()` та `includes()`.
3. `js/task-3.js` — `sortByDescendingFriendCount(users)`: сортування за спаданням кількості друзів через `toSorted()`.
4. `js/task-4.js` — `getTotalBalanceByGender(users, gender)`: сума балансів через ланцюжок `filter()` та `reduce()`.

Відкрийте `index.html` у сучасному браузері та перегляньте консоль

Форматування з кореня цієї папки:

```sh
npx prettier --write .
npx prettier --check .
```
